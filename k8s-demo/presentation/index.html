📄Déploiement Kubernetes — Manifests YAML

# backend-deployment.yaml (extrait)
apiVersion: apps/v1
kind: Deployment
spec:
  replicas: 1
  strategy:
    type: Recreate # ← crucial
  containers:
  - name: flask
    image: alexandraassaga/moto-backend
    resources:
      limits:
        memory: "256Mi"
        cpu: "300m"
  - name: mongodb
    image: mongo:7.0
    volumeMounts:
    - mountPath: /data/db

Difficultés Rencontrées

🔒
Conflit mongod.lock (CrashLoopBackOff)
Deux pods montaient le même PVC simultanément lors d'un rollout restart → verrou bloqué
💥
OOM Kill (exit code 137)
Lancer mongosh dans le conteneur MongoDB (512Mi) en plus de mongod dépassait la limite mémoire
👤
User MongoDB inexistant (UserNotFound)
Les variables MONGO_INITDB_* ne fonctionnent que sur un volume entièrement vide — rm -rf /data/db/* ne supprime pas les fichiers cachés
🖼️
Images motos invisibles
Noms de fichiers avec majuscules/espaces côté Windows, mais Linux est sensible à la casse → images non trouvées par Nginx
🔗
Hook git installé au mauvais endroit
La racine git étant à C:\Users\alexa\ (et non dans k8s-demo/), le hook était dans un .git\ inexistant
⏱️
Race condition au démarrage
Flask tentait de se connecter à MongoDB avant que celui-ci soit prêt → boucle d'échecs d'authentification

Solutions Apportées

✅
strategy: Recreate
Ajouté dans le Deployment backend → l'ancien pod est supprimé avant que le nouveau démarre, libérant le PVC
✅
Bypass via container Flask
Au lieu de mongosh, utilisation de python3 -c avec PyMongo déjà chargé → aucune mémoire supplémentaire consommée
✅
Création manuelle de l'utilisateur MongoDB
Pod temporaire avec mongod --noauth + getSiblingDB('admin').createUser() via mongosh
✅
Convention de nommage kebab-case
Renommage des images en minuscules sans espaces (bmw-r1250gs.jpg) + rebuild de l'image Docker frontend
✅
Détection automatique de la racine git
git rev-parse --show-toplevel dans le script d'installation pour trouver le bon dossier .git/hooks/
✅
Wipe complet avec find
find /data/db -mindepth 1 -delete au lieu de rm -rf * pour supprimer également les fichiers cachés
